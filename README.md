## ✨ 主要功能

### 👤 人脸打码

自动检测图片和视频中的人脸，无需逐帧手动框选。

支持：

- 所有人脸自动打码
- 根据参考照片，仅打码指定人物
- 根据参考照片，保留指定人物并打码其他人
- 可调节人脸识别灵敏度
- 支持多张参考人脸照片

适合视频发布、采访素材、教学录制等需要保护人物身份的场景。

### 🧍 人体打码

自动识别完整人物区域并进行遮挡。

相比只处理人脸，人体打码还可以隐藏衣着、身体轮廓和人物整体外观，适合监控画面、工作资料以及需要隐藏完整人物信息的场景。

### 🚗 车牌打码

自动检测图片和视频中的车牌并进行遮挡。

对于高分辨率画面或远距离车辆，可开启 **小车牌增强**，辅助识别尺寸较小的车牌。

### 🎭 多种遮挡方式

支持：

- 马赛克
- 高斯模糊
- 自定义图片覆盖

可根据实际需求调整遮挡范围和效果强度。

### 🖼️ 图片与视频处理

支持：

- JPG / JPEG / PNG / BMP / WebP 图片输入
- 图片批量处理
- MP4 视频处理
- 自动生成处理结果
- 长视频流式处理

### ⚡ CPU / GPU 推理

普通电脑使用 CPU 即可运行，无需独立显卡。

同时支持 Windows **DirectML GPU 加速**，在兼容的 NVIDIA、AMD 或 Intel GPU 上可提升 AI 推理速度。

### 🔒 本地 AI 处理

AI 模型、目标识别和文件处理均在本机执行：

- 不上传图片
- 不上传视频
- 不上传人脸数据
- 不依赖云端识别接口
- 图片和视频处理可在本地完成

## 使用方式

基本流程只需要三步：

1. 导入图片、图片文件夹或视频
2. 选择需要打码的目标和遮挡方式
3. 点击开始处理

软件会自动完成目标识别、遮挡和结果导出。

## 适用场景

- 短视频和自媒体内容发布
- 采访及街拍素材处理
- 教学和会议录像
- 企业资料脱敏
- 监控及公共场所素材处理
- 车辆及车牌隐私保护
- 人像隐私保护

## 系统要求

### 操作系统

- Windows 10 64 位
- Windows 11 64 位

### 硬件

- Intel / AMD CPU
- 建议 4 GB 以上内存
- GPU 非必需
- 使用兼容显卡时可启用 DirectML GPU 加速

## 隐私说明

**AI 打码采用本地 AI 处理方式。**

导入的软件图片、视频及参考人脸照片均用于本机处理，无需上传到远程服务器。
